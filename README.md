# Automação de Indicadores de Lojas

Projeto prático do curso Python Impressionador (Hashtag Treinamentos).

## O que o projeto faz
- Lê as vendas de 25 lojas e calcula o OnePage de cada uma (faturamento, diversidade de produtos e ticket médio, no dia e no ano)
- Salva uma planilha por loja em pasta própria, com a data (backup)
- Envia por e-mail a cada gerente apenas os dados da sua loja
- Gera o ranking diário e anual de faturamento e envia à diretoria

## Tecnologias
Python, pandas, pywin32 (envio de e-mail pelo Outlook)

## Como rodar
1. Instale as bibliotecas: `pip install pandas openpyxl pywin32`
2. Coloque as planilhas de vendas, e-mails e lojas na pasta `Bases de Dados` (não estão incluídas aqui, pois pertencem ao curso)
3. Ajuste os caminhos das planilhas no notebook para o seu computador
4. Execute o notebook `Automacao de Processo.ipynb`
